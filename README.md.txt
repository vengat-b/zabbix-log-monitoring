# Linux Server Monitoring with Zabbix + Automated Log Cleanup Script

This project demonstrates how to set up **enterprise-grade Linux server monitoring** using **Zabbix 6.0 LTS** on **CentOS Stream 9**, combined with a **custom shell script** that automatically cleans old log files and reports its status to Zabbix.

The project covers:
- Zabbix Server installation & configuration
- Zabbix Agent setup
- Custom monitoring using UserParameter
- Automated log cleanup script (bash)
- Monitoring the script execution result
- Trigger configuration for alerting
